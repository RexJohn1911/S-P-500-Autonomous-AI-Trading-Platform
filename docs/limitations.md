## 2. Distinction of Execution and Validation States

To prevent ambiguity, the platform clearly distinguishes between the following operational states:
1. **Tested Component**: Individual algorithms, loss functions, feature calculators, and risk checks validated by unit/integration tests (372 automated tests).
2. **Persisted Paper-Session Telemetry**: Real execution history, orders, fills, account balance curves, and checkpoints saved to durable storage (`models/paper_trading/` and `models/autonomous/`) generated by `backend/scripts/run_paper_cycle.py`.
3. **Currently Running Autonomous Process**: Single-worker stateful daemon actively listening for market events and executing cycles in memory. Shows `STANDBY` when no session is actively running.
4. **Production Deployment Validated**: Configuration and environment validated by `backend/scripts/deploy_check.py` with strict zero-tolerance exit codes.
5. **Live Broker Verified**: Dynamic verification via bounded, read-only account query confirming active authentication with the exchange or reporting `DISCONNECTED` / `UNAUTHENTICATED`.

## 3. Third-Party Library Deprecation Warnings

The platform codebase produces zero internal errors. For complete transparency, the test suite encounters known upstream third-party library deprecation warnings in the Python scientific ecosystem:
1. **Keras / TensorFlow (`keras/src/backend/tensorflow/core.py`)**: `DeprecationWarning: __array__ implementation doesn't accept a copy keyword` (NumPy 2.0 array protocol transition).
2. **hmmlearn (`hmmlearn/utils.py`)**: `DeprecationWarning: Setting the shape on a NumPy array has been deprecated in NumPy 2.5`.
3. **LightGBM (`lightgbm/sklearn.py`)**: `LGBMDeprecationWarning: The argument 'eval_set' is deprecated, use 'eval_X' and 'eval_y' instead`.
4. **Starlette TestClient (`fastapi/testclient.py`, `starlette/testclient.py`)**: `StarletteDeprecationWarning: Using 'httpx' with 'starlette.testclient' is deprecated` and `anyio.abc.BlockingPortal alias is deprecated`.

These warnings originate within external upstream vendor packages and do not impact runtime correctness or mathematical precision.

## 4. Universe & Market Data Scope
1. **Default Active Symbol Coverage**: The reproducible dataset bundled within the repository includes validated daily bar data for **AAPL** (2023–2025), **SPY** (benchmark), and **TSLA** under `data/raw/` and `data/processed/`.
2. **Full S&P 500 Constituent Universe**: The architecture is fully generic and ready to ingest the complete 500-constituent S&P 500 universe when connected to an external market data provider (e.g. Alpaca Market Data API, Polygon.io, or institutional database feeds). Full 500-constituent execution should NOT be claimed without ingesting the complete universe dataset.
3. **Data Freshness**: Local Parquet and JSON files represent historical daily bars. Live real-time market data streaming requires configured broker API credentials.

## 5. Execution & Broker Limitations
1. **Zero Real-Money Validation**: The platform was tested exclusively using historical market datasets, simulated paper execution, and the Alpaca sandbox/paper trading environment. Real-money live capital execution was NOT tested.
2. **Simulated Market Microstructure**: While the backtesting and paper trading engines model commissions, slippage, half-spreads, borrow costs, and market impact, they cannot perfectly capture queue priority, dark pool liquidity, or market impact in extreme flash-crash conditions.
3. **Single-Worker Process Requirement**: The autonomous loop scheduler, in-memory event bus, Global Kill Switch, and reconciliation watchdog require a single ASGI worker process (`WORKERS_COUNT=1`). Horizontally scaling multiple concurrent ASGI worker processes without an external distributed lock coordinator is unsupported.

## 6. Quantitative & Machine Learning Limitations
1. **No Profitability Guarantees**: Machine learning metrics (accuracy, precision, PR-AUC) and historical backtest returns represent experimental research findings on past data. They do not constitute promises or guarantees of future live market returns.
2. **Regime Sensitivity**: AI model performance and signal confidence can vary significantly across unforeseen macroeconomic shocks or structural market regime shifts.
